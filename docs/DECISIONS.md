# PDD interpretation and implementation decisions

These decisions resolve contradictions in the PDD before implementation. Update this file when evidence changes a decision.

1. **Deployment**: user requests Free Edition. Use serverless Spark Connect, managed Unity Catalog tables/volumes, bounded `availableNow` streams. The PDD's Azure DS5 four-worker cluster, RDD simulation, DBR pinning, autoscaling and spot policy are incompatible. Do not claim these were deployed.
2. **Medallion boundaries**: Bronze stores original immutable EIA observations/responses; Silver is validated and deduplicated price/operations data; Gold contains reporting facts and aggregates. The PDD places enriched prices in Bronze inconsistently. Keep raw and enriched separate.
3. **Missing schemas**: explicitly add flights, simulation raw distributions, ingestion/run registries, quality results and BI dimensions. Raw simulated costs do not belong in the aggregate risk table.
4. **VaR naming**: absolute P95 budget cost is `p95_cost_b`; incremental VaR is `var_95_b = p95_cost_b - mean_cost_b`. CVaR conditions on **absolute P95**, never on incremental VaR. The source example inconsistently labels P95 as VaR and subtracts median elsewhere. Expose both clearly.
5. **Calibration**: use lambda 0.94 EWM weekly returns, not plain mean/std. For annual GBM arithmetic drift, `mu = 52*E[weekly log return] + sigma²/2`. S0 is the latest observation, not maximum price. Establish regular weekly calendar sampling and reject gaps during calibration. Daily analytics annualize daily returns appropriately; daily updates and weekly simulation are separate concepts.
6. **90-day windows**: calendar interval windows, not 91 rows. Use Pearson correlation directly. Source correlation CTE omits `crack_spread` and mixes different window means; correct both.
7. **Region and sources**: EIA petroleum spot series includes Gulf Coast jet fuel; source calibration text calls it East Coast. Use the actual verified EIA series/region consistently, with metadata. Never relabel Gulf Coast as East Coast.
8. **Costs and P&L**: route `hedge_cost_difference_usd = hedged − unhedged` is negative for savings. Long futures unrealized gain is `(spot − locked)*gallons`, positive when in the money. Keep separate names; the PDD's MTM narrative has its sign reversed.
9. **Instrument scope**: direct jet fuel futures delta model is implemented first. WTI/heating oil marks use matching converted proxy prices and disclose basis risk. Options/collars require additional strikes, maturities, vol surfaces and valuation models; reject unsupported pricing rather than fabricating it. Premium affordability cannot be optimized without an explicit premium/budget constraint; futures carry is separately disclosed.
10. **Paths and horizons**: share random price paths between ratios; deterministic path IDs/seeds independent of partitions; mean purchase price uses future weekly observations. Annual gallons × horizon scales total costs. Default horizon one year, five ratios and 100K paths.
11. **Run selection and keys**: use explicit run UUID plus timestamps/status registry, never lexical MAX(UUID). Deterministic hashes or natural keys replace unnecessary identity columns. Partition only on physical columns; `PARTITIONED BY(YEAR(price_date))` in source is not valid Delta DDL.
12. **Operations grain**: reference 1.5B gallons is separate from fixture fleet volume. Historical route costs use as-of prices and valid routes; latest spot is a forward scenario assumption, not silently substituted into historical costs. Hedge scenario sweeps must not multiply flight counts in aggregate totals.
13. **Truthfulness**: tests on synthetic data demonstrate behavior, not real risk findings. Cloud execution, GitHub issues, Power BI connection and MLflow runs require actual evidence before claiming success.
14. **Reporting publication**: current-source readiness guards supplement run registries. Consumers import `*_current` views only after the sequential refresh succeeds; separate Power BI Import queries are not an atomic snapshot. Old runs remain history and never silently become current-source risk.
15. **Operational refresh**: Free Edition supports the project's actual EIA egress and project secret scope in live checks. Use bounded full-history daily recapture to propagate old revisions, sequential job tasks and one concurrent run. Do not widen secret ACLs or embed credentials. Versioned notebook paths preserve deployed source. No destructive retention policy is automatically applied.
16. **External packaging**: executed notebook, source, results, charts, Power Query/DAX and five-minute recording script are delivered. Power BI Desktop connection/report creation and Loom recording/upload require the user's application/account and are not claimed as executed validations.


## Phase 5 — Historical evidence and report (2026-10-21)

17. **Descriptive ranks**: use SQL PERCENT_RANK semantics, `(minimum tied rank - 1)/(N-1)`, excluding missing values. Jet/crack ranks are **full-sample**, including the current year, and describe historical position, not ex-ante probabilities. The prior-years crack benchmark is 2010 through the calendar year before the current observation (2010–2025 for this extract). Monthly decomposition averages components on the same daily rows; WTI/42 + crack equals jet on observed pairs. Daily waterfall endpoints use the latest observation at or before the same calendar date twelve months earlier.
18. **Two different correlation measures**: leave Silver `rolling_corr_90d` untouched and label it `price_level_corr_jet_wti_90d` in the insight fact. New correlations use paired daily log returns and SQL `RANGE BETWEEN INTERVAL 90 DAYS PRECEDING AND CURRENT ROW` semantics: **both endpoints inclusive**, minimum 20 paired returns. This boundary convention reproduces the supplied 0.496/0.912 return correlations. It is not pandas' default open-left 90D window; the legacy Silver price-level window retains its original 89-preceding/current implementation. Never describe price-level correlation as hedge effectiveness. Nonpositive WTI (April 2020), missing proxy legs or a missing adjacent observation invalidate that leg's return. Any long return gap anywhere in the range suppresses the correlation; there is no price imputation.
19. **Proxy effectiveness**: sample each price leg's last actual observation in a complete W-FRI week; retain empty weeks and drop returns spanning them. Annual grouping uses the return's ending week. R² is squared paired-return Pearson correlation; beta is sample covariance divided by proxy sample variance in common $/gal units. `ALL` is a separate full-sample row, never an aggregate of annual R². R²≥0.80 is a descriptive benchmark, not an accounting eligibility determination.
20. **Historical hedge windows**: every weekly start with exactly 52 future weekly observations, excluding S0, fixes F=S0·exp(0.04). `savings_per_gal = realized_average - F` is the hypothetical fully covered unit saving; ratio h scales the reference-carrier budget cost. Windows overlap and are not independent trials. Budget overrun is relative to that window's S0 run-rate and can be negative. The frontier x coordinate is mean budget overrun; the title's expected hedge cost is the difference of means, 80% minus 0%. The reference carrier is 1.5B gal/year, not the synthetic fixture schedule.
21. **Calibration history/reference population**: reuse `calibrate()` unmodified, 365-day lookback, only returns through the calibration week. Require 52 weeks of initial history, rather than the production function's minimum 26 observations. There are 822 valid calibrations through 2026-10-02; 770 also have a complete subsequent purchase year. Store all 822 in `calibration_history` and rank against that complete calibration population (current μ rank 94.3%, median 9.1%). The supplied 96th-percentile/6.6% median benchmark used the 770 completed-outcome population; restricting that population is not appropriate for a chart labelled all calibrations. `is_current` must reconcile with the latest successful production simulation's μ/σ within 1e-9 in the live verifier.
22. **Walk-forward simulation**: 10,000 paths per calibrated complete-outcome window, EWM sigma and drifts EWM/zero/4%. Use the existing `price_paths()` Box–Muller/PCG64 implementation. Encode path ID as window_index + path_id·2^32 with the original 32-bit base seed: SeedSequence expands it exactly as `[base_seed,window_index,path_id]`, including window zero. Share paths across drift models via the exact GBM drift rescaling, and average only the 52 future purchases. No production calibration/default changes. Execution is serverless mapInPandas, eight partitions; partitioning cannot alter a path. Store window index/base seed/path count to reproduce every quantile. Independent oracle uses separate covariance/EWM/Box–Muller equations, scalar calendar masks and direct GBM paths; input/function-hashed caches reuse only identical oracle work. Compare all deterministic and MC values within 1e-9, stronger than the requested coverage tolerance.
23. **Tail diagnostics**: standardized complete weekly jet log returns use full-sample arithmetic mean and sample standard deviation. Frequency is observed `abs(z)>k`; normal comparison is erfc(k/sqrt(2)). pandas' unbiased sample skew and Fisher excess kurtosis are descriptive, not a fitted alternative stochastic model. Drift extrapolation bias and Gaussian tail misspecification are distinct, and need not cancel.
24. **Insight publication**: append-only, run-keyed new facts and per-table quality history; newest insight run (including STARTED) must match the latest successful Silver/quality source. All seven actual row counts must match seven distinct positive expected counts from that same run/source. Missing inputs or interrupted writes fail closed. The additive `insights_ready` leaves analytics/risk flags' original expressions unchanged. In the managed job, insights run immediately after Silver, before operations/risk and final reporting publication; insights do not depend on simulation completion. The standalone deploy additionally publishes the additive reporting contract. No destructive history retention or schema permission change.
25. **Semantic model/report**: credential-free existing GoldTable M, Import only, single-direction dimension→fact relationships. Daily facts use dim_date; historical windows/calibrations stay disconnected. All measures live in `_Measures`; starter measures retain their meanings. Percentiles/R²/correlations use SELECTEDVALUE or correctly scoped table-level computations, never sums. Historical P95 is computed from individual window overruns (not from percentile rows). Route costs require exactly one scenario; gallons/unhedged costs retain the scenario-zero pattern. Readiness/date/completion/run tooltip appear on each page; current-view emptiness means unavailable, never zero. Existing MTM/sensitivity imports are additionally gated by analytics readiness in M.
26. **Layered report visuals**: use certified AppSource Deneb for dual-axis calibration/IQR, actual P05–P95/P25–P75 fan bands and histogram bars/rules. PBIR configuration follows the visual author's published [PBIR guide](https://deneb.guide/docs/pbir-guide). Desktop retrieves the certified GUID; no downloaded executable is vendored. Native visuals handle the other units. Vega-Lite JSON schema and compiler checks supplement Microsoft PBIR schemas. Exact embedded spec previews are labelled as such, and never substitute for Desktop screenshots. Explicit labels, markers, dashes/hatches and signed values support the required palette under color-vision deficiencies.
27. **Evidence boundaries**: `phase5_offline_verification.json` and offline storyboard badges explicitly identify local development extracts. Only `phase5_verification.json` may attest live SQL reconciliation. Microsoft TOM parse proves TMDL syntax, not DAX evaluation or Desktop rendering. DAX query-view tests and SQL equivalents are supplied separately; a SQL pass does not mean DAX was executed. Native app automation approval timed out before project open; the Desktop authentication/refresh/screenshot checklist remains a separate gate until actually executed.
