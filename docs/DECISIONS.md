# PDD interpretation and implementation decisions

These decisions resolve contradictions in the PDD before implementation. Update this file when evidence changes a decision.

1. **Deployment**: user requests Free Edition. Use serverless Spark Connect, managed Unity Catalog tables/volumes, bounded `availableNow` streams. The PDD's Azure DS5 four-worker cluster, RDD simulation, DBR pinning, autoscaling and spot policy are incompatible. Do not claim these were deployed.
2. **Medallion boundaries**: Bronze stores original immutable EIA observations/responses; Silver is validated and deduplicated price/operations data; Gold contains reporting facts and aggregates. The PDD places enriched prices in Bronze inconsistently. Keep raw and enriched separate.
3. **Missing schemas**: explicitly add flights, simulation raw distributions, ingestion/run registries, quality results and BI dimensions. Raw simulated costs do not belong in the aggregate risk table.
4. **VaR naming**: absolute P95 budget cost is `p95_cost_b`; incremental VaR is `var_95_b = p95_cost_b - mean_cost_b`. CVaR conditions on **absolute P95**, never on incremental VaR. The source example inconsistently labels P95 as VaR and subtracts median elsewhere. Expose both clearly.
5. **Calibration**: use lambda 0.94 EWM weekly returns, not plain mean/std. For annual GBM arithmetic drift, `mu = 52*E[weekly log return] + sigma²/2`. S0 is the latest observation, not maximum price. Establish regular weekly calendar sampling and reject gaps during calibration. Daily analytics annualize daily returns appropriately; daily updates and weekly simulation are separate concepts.
6. **90-day windows**: calendar interval windows, not 91 rows. Use Pearson correlation directly. Source correlation CTE omits `crack_spread` and mixes different window means; correct both.
7. **Region and sources**: EIA petroleum spot series includes Gulf Coast jet fuel; source calibration text calls it East Coast. Use the actual verified EIA series/region consistently, with metadata. Never relabel Gulf Coast as East Coast.
8. **Costs and P&L**: route `hedge_cost_difference_usd = hedged − unhedged` is negative for savings. Long futures unrealized gain is `(spot − locked)*gallons`, positive when in the money. Keep separate names; the PDD's MTM narrative has its sign reversed.
9. **Instrument scope**: direct jet fuel futures delta model is implemented first. WTI/heating oil marks use matching converted proxy prices and disclose basis risk. Options/collars require additional strikes, maturities, vol surfaces and valuation models; reject unsupported pricing rather than fabricating it. Premium affordability cannot be optimized without an explicit premium/budget constraint; futures carry is separately disclosed.
10. **Paths and horizons**: share random price paths between ratios; deterministic path IDs/seeds independent of partitions; mean purchase price uses future weekly observations. Annual gallons × horizon scales total costs. Default horizon one year, five ratios and 100K paths.
11. **Run selection and keys**: use explicit run UUID plus timestamps/status registry, never lexical MAX(UUID). Deterministic hashes or natural keys replace unnecessary identity columns. Partition only on physical columns; `PARTITIONED BY(YEAR(price_date))` in source is not valid Delta DDL.
12. **Operations grain**: reference 1.5B gallons is separate from fixture fleet volume. Historical route costs use as-of prices and valid routes; latest spot is a forward scenario assumption, not silently substituted into historical costs. Hedge scenario sweeps must not multiply flight counts in aggregate totals.
13. **Truthfulness**: tests on synthetic data demonstrate behavior, not real risk findings. Cloud execution, GitHub issues, Power BI connection and MLflow runs require actual evidence before claiming success.
